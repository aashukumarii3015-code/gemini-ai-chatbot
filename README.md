🤖 Gemini AI Chatbot

A simple AI chatbot built with Python and the Google Gemini API that allows users to interact with an AI model through the command line.

✨ Features

- Interactive AI conversations
- Real-time AI-generated responses
- Google Gemini API integration
- Python-based implementation
- Simple command-line interface

🛠️ Technologies Used

- Python
- Google Gemini API
- Generative AI

🚀 How to Run

1. Clone the repository.
2. Install the required library:
   ```bash
   pip install google-genai
   ```
3. Open the Python file.
4. Replace:
   ```python
   YOUR_GEMINI_API_KEY
   ```
   with your own Gemini API key.
5. Run the program:
   ```bash
   python geminiAI.py
   ```

🔐 API Key Security

Do not upload your actual API key to GitHub. Use your own API key locally when running the project.
